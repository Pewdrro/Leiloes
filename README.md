LeiloesTDSat

Sobre o projeto

Sistema desktop Java para cadastro e consulta de produtos de uma casa de leiloes.
O projeto utiliza telas Swing criadas no NetBeans e organiza o acesso aos dados
por meio das classes DAO e DTO.

Tecnologias utilizadas

- Java
- Swing
- NetBeans
- MySQL
- JDBC

Estrutura principal

- cadastroVIEW: tela de cadastro de produtos;
- listagemVIEW: tela de consulta dos produtos;
- ProdutosDTO: representa os dados do produto;
- ProdutosDAO: concentra as operacoes de acesso aos produtos;
- conectaDAO: configura a conexao JDBC com o MySQL.
